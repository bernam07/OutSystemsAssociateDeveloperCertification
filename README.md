# OutSystems Associate Developer Certification (O11 & ODC)

Repositório com os materiais de estudo, simulados, guia de revisão e simulador interativo usados na preparação para as certificações **OutSystems Associate Developer (O11)** e **Associate Developer (ODC)**.

## Estrutura do Repositório

```text
.
├── index.html                          # Simulador interativo (200 perguntas, Modo Estudo e Modo Exame)
├── docs/
│   ├── guia_revisao_outsystems.md      # Guia de revisão focado nos erros + Cheat Sheet O11
│   ├── Detail sheet.en-US.11.pdf       # Detail sheet oficial do exame Associate Developer (O11)
│   └── From O11 to OutSystems Developer Cloud Cheatsheet.en-US.ODC.pdf
└── exames/
    ├── pdf/                            # 4 simulados originais em PDF (50 perguntas cada)
    ├── extraidos/                      # Extração completa em Markdown das 200 perguntas e respostas
    └── respostas/                      # Fotos das folhas de respostas das tentativas feitas
```

## Simulador Interativo (`index.html`)

O ficheiro `index.html` contém uma aplicação web 100% offline com todas as **200 perguntas** dos 4 exames:

- **Exames 1 a 4** (50 perguntas cada, com 2 correções de gabarito sinalizadas face à documentação oficial)
- **Modo Só Erradas** (33 perguntas erradas nas tentativas anteriores)
- **Simulado Aleatório** (50 perguntas sorteadas das 200)
- **Modo Estudo** (feedback imediato) e **Modo Exame** (cronómetro de 2h00, critério de aprovação ≥ 70%)
- **Atalhos de teclado:** `A / B / C / D` para responder e `← / →` para navegar

> Basta abrir `index.html` diretamente no browser (ou ativar **GitHub Pages** na branch `main` para o usar online).
